# Agent 上手与经验索引

更新时间：2026-09-13。这里记录在本仓库实际完成的工作、可复用的方法和失败教训。当前覆盖以普通对话 Agent、技能提示词、测试和本机部署为主，不声称覆盖 Android、Web 或全部业务。

## 新 Agent 先做什么

1. 读取用户本轮要求及适用的 AGENTS.md；本目录是交接经验，不替代用户授权或当前项目规则。
2. 在 P:/PonyChat 执行 `git status --short`、`git log -5 --oneline`，确认并行改动。不要提交其他任务的文件。
3. 按任务阅读下列专题。涉及部署先读 [官方部署流程](../Backend/deploy/README.md)。
4. 运行状态以代码、生产进程、部署标记和工具结果为准；文档中的日期和提交只作为核对线索。

| 文档 | 用途 |
| --- | --- |
| [普通对话与技能](chat-skills.md) | 找到技能、动态注入和配套代码；理解用户已确认的边界 |
| [测试经验](testing.md) | 真实模型、多轮历史、并发测试、原始输出保留与失败教训 |
| [部署经验](deployment.md) | 本机发布、20并发、回滚和重启陷阱 |
| [交接快照](snapshot-20260913.md) | 已完成工作、已知不足、提交与报告入口 |

## 维护方式

- 每条经验尽量说明条件、实际现象、处理方法、证据路径和日期。
- 区分规则要求、用户偏好、代码当前行为、单次观察以及尚未验证的推测。
- 易变化的运行状态放在带日期的快照；不要把旧部署目标、版本号和配置当永久事实。
- 不存密钥、令牌、生产聊天原文或用户个人资料；环境文件只记名称和相关非敏感配置项。
- 更新经验需要用户授权或当前任务明确要求；不要把这里变成每轮自动追加的日志。
