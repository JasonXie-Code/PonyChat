# PonyChat 项目近况说明（2026-06-03）

> 这页面向关心 PonyChat 的朋友，按仓库 `change-log/` 汇总近期状态。它不是完整开发日志，只挑和产品体验、网站、语音、角色系统、部署有关的重点说清楚。

---

## 一、当前产品状态

PonyChat 仍然把核心放在 **Android 客户端里的小马角色长期陪伴**：普通聊天、长期记忆、主动消息、角色大厅、语音和陪玩相关能力都围绕「你和角色的关系」展开，而不是做泛社交平台。

3 月曾有过放慢节奏的整理说明，但 4 月到 6 月项目已经继续推进。现在的状态更接近：

- **普通聊天** 是主线能力，服务端消息表是权威历史，Android 只上传最新用户消息增量，历史记录按服务端分页加载。
- **Galgame / 锁分模式** 仍由 `Backend/galgame/` 与 Android 原生 UI 承载，和普通聊天的长期记忆隔离。
- **语音消息** 已进入普通聊天链路：角色可生成语音脚本，按句带情绪提示合成，并在 Android 端以语音气泡展示。
- **角色大厅与角色主页** 正在完善：公开角色、官方角色引用、角色主页素材、相册、16 人格、喜欢数据都已接入或迭代中。
- **网站** 负责官网、下载、轻量网页聊天、MBTI 入口与后台管理；完整体验仍以 Android 客户端为主。

## 二、最近完成的重点

### 1. 普通聊天历史权威化

普通聊天不再让 Android 反复回写整段会话。后端会按服务端数据库历史重建上下文，再合并本次用户消息。这样可以减少历史覆盖、竞态和多端通知混乱。

配套更新包括：

- Android 历史页分页加载服务端消息。
- `POST /api/messages/hide` 支持按用户、角色、会话和消息 ID 软隐藏单条普通聊天消息。
- 主动消息、定时 follow-up 和多段回复会按消息段分别入库、入 outbox，并保持顺序。

### 2. 普通聊天语音消息链路

普通对话导演步骤现在会判断本轮回复使用文本还是语音。若选择语音，后端进入专门的语音回复步骤，生成更适合朗读的脚本。

当前语音链路已经覆盖：

- 按句生成 `sentence` 与 `emotion_prompt`。
- 调用 Voice Lab / Qwen3TTS 合成，并用 `ffmpeg` 拼接音频。
- 括号旁白可作为文本段展示，不送入 TTS。
- emoji 和不适合朗读的符号会从 TTS 文本中清理，聊天气泡原文仍保留。
- 服务端短期缓存音频，Android ACK 后清理；历史、本地音频缺失、分享和导出场景都可回退显示文本。
- 多段语音会提前并发预热合成，但仍按原始气泡顺序下发，避免乱序。

Android 端也同步重做了语音气泡：宽度随时长变化，波形可显示播放进度，支持拖动进度、转文字展开、分享导出和菜单操作。

### 3. 角色主页与公开档案

Android 新增角色主页，用于角色大厅和角色详情的公开档案展示。角色主页包含封面、头像、作者、个性签名、人气数据、相册、16 人格和角色档案。

近期相关变化：

- 角色大厅点击角色卡片进入角色主页。
- 本地角色列表点击主体仍直接进入对话，三点菜单保留管理入口。
- 对话顶部点击角色头像或角色名进入角色主页。
- 封面和相册支持全屏预览与下载。
- 角色编辑页可维护个性签名、主页素材、性格、兴趣和 16 人格。
- 官方角色对非 System 用户只读，避免误编辑官方源。

### 4. 官方角色源与 ID 迁移

后端现在会把 `System` 账号创建或保存的角色标记为官方源角色。角色大厅添加逻辑改为动态识别数据库中的官方源，不再只依赖固定小马角色 ID 列表。

管理后台支持在创建和编辑角色时维护角色 ID。编辑已有角色 ID 时不会直接硬改 `characters.id`，而是执行安全迁移，同步更新对话、记忆、Galgame、主动消息、图片上下文等引用表。

生产环境已经完成 Jason 名下旧版同名官方角色融合：旧“紫悦”和“碧琪”的历史对话与记忆迁入对应官方引用 ID，旧角色隐藏并保留 `mergedInto` 记录，方便回溯。

### 5. Voice Lab 与 TTS

`voice.ponychat.org` 已拆成双引擎工作台：

- Qwen3TTS：入口为 `/`、`/qwen3tts` 与旧版无前缀 API。
- OmniVoice：入口为 `/omnivoice/` 与 `/omnivoice/*` API。

Voice Lab 目前支持 Redis 任务队列、后台 worker、任务轮询、预置说话人、情绪/风格 instruct、分段情绪合成和下载接口。OmniVoice 增加了 instruct 归一化与更短的中文错误提示。Qwen3TTS 侧也修复了分句拼接时的 pop 声，收紧采样参数以降低角色音色漂移。

官方小马角色已开始接入对应 qwen3tts 音色，角色级 `voice_id`、`voice_instruct` 和语音策略仍支持覆盖。

### 6. LLM 静态站与视觉输入

新增 `PonyChat-Website/LLM/`，用于本地 OpenAI-compatible LLM 聊天站。它支持 `/v1/models`、`/v1/chat/completions`、流式输出、图片输入、Markdown、KaTeX 和思维链折叠。

近期修复了图片上传后可能触发 nginx `502 Bad Gateway` 的问题：前端会压缩大图，错误处理也会把 HTML/nginx 错误页转成可读提示，避免把整段 HTML 塞进聊天气泡。

## 三、仍在推进或尚未开始的方向

| 方向 | 状态 | 说明 |
|------|------|------|
| 聊天陪玩 | 进行中 | 经典 `/api/companion/frame`、`/api/companion/stream`、`/api/companion/end` 与 ASR/TTS WebSocket 可用；Android 的 `/ws/companion/realtime` 桥接代码存在，但后端实时路由尚未挂载。 |
| 操作类陪玩 | 攻关中 | 仍依赖视觉理解、游戏状态判断、系统控制和低延迟链路。 |
| 音乐共同欣赏 | 待开始 | 计划结合 MediaSession、记忆和主动消息。 |
| 视频共同讨论 | 待开始 | 计划围绕链接解析、画面截图和实时讨论展开。 |
| 剧情模式 | 规划中 | 会与普通聊天隔离，结局重玩不回写长期记忆。 |
| 游戏 AI 真实参与 | 规划中 | 先从棋牌方向验证，再评估动作游戏与第二台设备方案。 |

## 五、写在最后

PonyChat 近期的开发重心不是铺很多新模式，而是把已经会影响日常体验的链路打稳：普通聊天历史、语音消息、角色主页、官方角色源、Voice Lab 和部署验证。

长期目标没有变：让小马角色从一次性对话，慢慢走向更像长期相处的 AI 伴侣。
