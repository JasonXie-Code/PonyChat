# 计分与抽题说明（72 题池）

## 1. 题库结构

- 共 **72 题**，四轴各 **18 题**：
  - 题号 **1–18**：EI（外向 E / 内向 I）
  - 题号 **19–36**：SN（实感 S / 直觉 N）
  - 题号 **37–54**：TF（思考 T / 情感 F）
  - 题号 **55–72**：JP（判断 J / 感知 P）
- 每题为**二选一**（左 / 右），在数据层记为 `L` 或 `R`。

权威数据文件：`docs/questions.json`（与 `web/src/data/questions.json` 保持一致）。

## 2. 单次测验如何抽题

从题库中**按轴均衡随机抽取**（不放回），再**整体打乱**展示顺序：

| 测验版本 | 每轴题数 | 总题数 |
|----------|----------|--------|
| 12 题简版 | 3 | 12 |
| 36 题完整版 | 9 | 36 |

即：先在 EI 的 18 题中随机抽 `k` 题，再在 SN、TF、JP 各抽 `k` 题（`k` = 3 或 9），将共 `4k` 道题合并后**随机打乱顺序**，避免「连续多题测同一维度」的观感。

每次重新选题量并开始测验时，会**重新抽题并重新打乱**，便于重复测试时有题目变化。

## 3. 单题计分

- 选**左选项**：为该题 `optionLeftPole` 一侧 +1。
- 选**右选项**：为 `optionRightPole` 一侧 +1。

仅统计**本次测验实际出现过的题号**上的作答。

## 4. 四轴判定与平局

对每一轴取分高的一侧字母；若**平局**，按下表取值（与实现代码一致）：

| 轴 | 平局时取 |
|----|----------|
| EI | **I** |
| SN | **N** |
| TF | **F** |
| JP | **P** |

四字母按 **E/I → S/N → T/F → J/P** 拼接。

同一轴上两侧得分可接近（非绝对二分）。结果页以**分布条**展示左端字母一侧得分占比（0–100%），中央竖线为 50% 参考；文案中「接近中间」表示与 50% 差距在约 8 个百分点以内（实现可调）。

## 5. 12 题与 36 题结果差异

简版每轴仅 3 个数据点，波动更大；完整版每轴 9 题，更稳定。产品文案建议区分「简版 / 完整版」。

## 6. 题库扩充

若需再扩充题量，建议仍保持**四轴题数一致**，并同步调整「每轴抽取数量」逻辑（例如仍为每轴 3 或 9 题）。
