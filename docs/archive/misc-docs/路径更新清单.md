## 📝 注意事项

### Web 文件访问路径

由于 HTML 文件移动到 `web/` 目录，访问路径变为：
- 前端入口：`http://localhost:8000/web/index.html` 或 `http://localhost:8000/`（后端路由重定向）
- 管理后台：`http://localhost:8000/admin`（后端路由重定向）

### Service Worker 作用域

Service Worker 现在注册在 `/web/sw.js`，作用域为 `/web/`，需要确保：
- 所有静态资源路径正确
- 缓存策略正常工作

### 日志文件位置

日志文件现在在 `.logs/backend.log`，确保：
- `.logs/` 目录有写入权限
- 日志轮转功能正常工作

### 数据库文件位置

数据库文件现在在 `database/ponychat.db`，确保：
- `database/` 目录存在
- 数据库文件有读写权限
