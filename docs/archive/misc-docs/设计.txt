# 角色扮演对话网页项目介绍

本项目是一款基于云端 AI 大语言模型驱动的角色扮演对话网页应用，旨在为用户提供高度沉浸、功能丰富的 AI 角色交互体验。项目支持多角色灵活切换与深度定制，集成了完整的用户账户体系、角色分享大厅以及全功能的管理后台。

## 🌟 核心亮点

*   **多模型支持**：支持 OpenAI、豆包、Grok、DeepSeek 等多种 AI 模型提供商，灵活切换，满足不同场景需求。
*   **多用户隔离架构**：完整的账户注册/登录系统，每个用户的角色数据、对话历史、偏好设置完全隔离，支持多人共用一台本地服务器。
*   **角色大厅生态**：内置角色分享社区，用户可一键将私有角色发布至大厅，或从大厅克隆他人的优质角色（自动生成独立副本），实现创意共享。
*   **全平台适配**：采用响应式设计，完美适配 PC、平板及移动端，提供原生 App 般的流畅触控体验。

## 🚀 已实现功能详情

### 1. 核心对话体验
*   **沉浸式聊天**：支持实时流式（Streaming）输出，Markdown 格式渲染，打字机效果。
*   **多模式参数调节**：
    *   **新手模式**：预设 "保守"、"普通"、"创意" 三种风格，一键切换。
    *   **专家模式**：开放 Temperature、Top P、Max Tokens 等底层参数微调。
*   **上下文管理**：可视化展示上下文 Token 使用情况，支持自动滑动窗口管理记忆。
*   **历史记录**：自动保存对话历史，支持查看过往对话流，并在不同会话间平滑切换。

### 2. 深度角色管理
*   **角色定制**：支持自定义头像、名称、简介、详细人设（Prompt）及强制指令（Instruction）。
*   **角色库管理**：直观的侧边栏角色列表，支持新建、编辑、删除操作。
*   **角色大厅 (Character Hall)**：
    *   **发布/取消发布**：将个人角色分享给所有用户。
    *   **搜索与发现**：支持按名称、作者、标签搜索公开角色。
    *   **克隆收藏**：一键将公开角色"搬"回个人库，自动断开与原版的关联，修改不影响原作者。

### 3. 系统管理后台 (Admin Dashboard)
*   **数据可视化**：实时监控用户总量、角色总量、对话活跃度及增长趋势。
*   **用户管理**：查看用户列表、注册时间、活跃状态，支持钻取查看特定用户详情。
*   **内容监管**：跨用户搜索和查看角色、对话记录，确保平台内容合规。
*   **系统状态**：监控模型加载状态及后端服务健康状况。

### 4. 运维与数据安全
*   **自动化备份**：提供 `backup_now.py` 脚本，支持一键全量备份项目数据（智能排除临时文件）。
*   **灾难恢复**：提供 `misc/restore_backup.py` 脚本，支持从 ZIP 归档快速恢复环境。
*   **双模式主题**：内置精心调教的 "暗夜模式" 与 "明亮模式"，适应不同光照环境。

## 🛠️ 技术架构

*   **后端**：Python FastAPI，处理 API 请求、用户认证、文件 IO 及与多种 AI 模型提供商的交互。
*   **前端**：原生 HTML5/CSS3/ES6+，无繁重框架依赖，轻量级且高性能。
*   **存储**：基于文件系统的 JSON 存储方案，结构清晰，便于迁移与备份。
*   **模型**：支持 OpenAI 兼容 API 接口，灵活对接多种云端AI服务。
