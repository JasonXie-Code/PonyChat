## 迁移脚本

### 对话和设置迁移
- **脚本位置**: `backend/db/migrate.py`
- **功能**: 迁移单个用户或所有用户的数据（角色、对话、设置、Galgame数据）
- **使用方法**:
  ```bash
  # 迁移所有用户
  python -m backend.db.migrate
  
  # 迁移指定用户
  python -m backend.db.migrate Jason
  ```

### 用户认证数据迁移
- **脚本位置**: `backend/db/migrate_users.py`
- **功能**: 迁移用户认证信息（用户名、密码等）
- **改进**: 已修复跳过已存在用户的问题，现在会更新缺失的密码数据
