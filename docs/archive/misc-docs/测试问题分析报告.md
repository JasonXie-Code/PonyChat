### 5. 🔴 **消息索引错误**（严重 Bug - 已修复）

**时间**：13:47:20.202
**错误**：`[建议生成] 找不到消息引用 (Index: 999)`

**日志证据**：
```
13:47:20.202 - [按钮检查] 消息999: isUser=false, isLast=true, isGen=true, isTyping=false, hasBubble=false, 显示=false
13:47:20.206 - [建议生成] 找不到消息引用 (Index: 999)
13:47:20.208 - [RenderChat] 普通模式渲染 - 加载了 2 条对话消息
```

**问题分析**：
- **根本原因**：在 `js/chat/chat-api.js` 中，错误消息使用了硬编码的索引 `999`
- 位置1：第662行 - 生成锁错误消息
- 位置2：第1219行 - 网络错误消息
- 当错误消息被追加后，如果它是最后一条消息，会触发建议生成
- 但索引999不存在于消息数组中，导致建议生成失败

**影响**：
- 建议生成失败
- 错误消息无法正确关联到消息数组
- 可能导致其他功能异常

**修复方案**：
- ✅ 已修复：将硬编码的 `999` 改为动态计算的消息索引
- 使用 `conv.messages.length` 作为错误消息的索引
