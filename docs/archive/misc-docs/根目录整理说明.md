1. **数据库路径**：如果应用启动时找不到数据库，检查 `database/` 目录是否存在
2. **日志文件**：如果 `backend.log` 被占用无法移动，可以手动关闭占用程序后移动

4. **备份建议**：整理前建议先备份整个项目

## 🔄 恢复方法

如果需要恢复文件到根目录，可以：

1. 从 `docs/` 恢复文档文件
2. 从 `scripts/` 恢复脚本文件
3. 从 `config/` 恢复配置文件
4. 从 `database/` 恢复数据库文件

或运行：
```bash
python scripts/organize_files.py  # 查看整理脚本了解文件映射关系
```
