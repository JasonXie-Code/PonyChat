# PonyChat 网页端定位（基于当前实现）

公开站点的主要职责是**项目与品牌展示**、**APK 下载入口**、**连接质量自测**、**管理后台入口**，以及面向浏览器的**网页版聊天（`/app`）**。  
主站由 `PonyChat-Website/Main/frontend`（Vite + Vue）构建的静态站提供，部署在 `https://ponychat.org/`；后端路由对历史路径统一做跳转处理。

---

## 1. 后端路由与重定向（`Backend/__init__.py`）

| 路径 | 方式 | 目标 | 说明 |
| --- | --- | --- | --- |
| `GET /` | 301 永久重定向 | `https://ponychat.org/` | 根路径跳转至官网 Vue 主站 |
| `GET /detail` | 301 永久重定向 | `https://ponychat.org/detail` | 产品介绍页（官网 Vue 路由） |
| `GET /html/detail.html` | 301 永久重定向 | `/detail` | 历史路径别名 |
| `GET /chat` | 302 临时重定向 | `https://ponychat.org/app` | 历史路径，引导至官网 Vue 网页版聊天 |
| `GET /html/index.html` | 302 临时重定向 | `https://ponychat.org/app` | 历史路径，同上 |
| `GET /admin` | 301 永久重定向 | `https://ponychat.org/admin` | 管理后台（官网 Vue 路由） |
| `GET /html/admin.html` | 301 永久重定向 | `https://ponychat.org/admin` | 历史路径别名 |

> `/html/css/*`、`/html/js/*`、`/html/fonts/*`、`/html/assets/*`、`/html/logo/*` 均 301 重定向至对应的无 `/html` 前缀路径，以兼容旧书签与相对路径请求。

---

## 2. 主站：Vue 静态站（`PonyChat-Website/Main/frontend`）

- **技术栈**：Vite + Vue，构建为静态文件，直接部署到 Server-USA（154.17.23.237）。
- **主要路由**：`/`（首页）、`/detail`（产品介绍）、`/app`（网页版聊天）、`/admin`（管理后台）。
- **视觉规范**：与 Android 应用图标一致——独角兽线稿 + 紫→青渐变，主色紫 `#A78BFA`、强调青 `#22D3EE`、深色底 `#0F172A`。
- **构建与同步**：见 `PonyChat-Website/Main/deploy/server-usa/DEPLOY-STATIC-WEB.md`。

---

## 3. 网页版聊天（`/app`）

- 官网 Vue 路由 `/app` 提供面向浏览器的普通对话入口，入口链接见 `PonyChat-Website/Main/frontend/src/views/HomeView.vue`。
- **能力范围**：仅普通对话；游戏/锁分模式为 **Android 原生**专属，网页版不提供。
- 业务 API 与 Android 客户端共用同一套 `/api/*` 端点。

---

## 4. 连接质量自测

- **能力**：延迟（`/api/ping` 三次均值）、下载（`GET /api/speedtest/download`）、上传（`POST /api/speedtest/upload`，随机体 256KiB）。
- **用途**：用户在安装 App 前粗测到本节点的网络状况；不替代 App 内完整路由与鉴权流程。

---

## 5. Android 安装包分发（`GET /download/apk`）

- **行为**：返回 `PonyChat.apk`（优先 `PonyChat-Website/Main/deploy/releases/PonyChat.apk`，兼容 `deploy/releases/PonyChat.apk`；否则回退本地 Gradle debug 产物）；无文件时返回 404 与说明文案。

---

## 6. 静态资源与图标

- **图标**：`/logo/logoBK512.png`；`GET /favicon.ico` 返回同 PNG 内容。
- **静态挂载**：`/logo`、`/css`、`/fonts`；`/js/*` 由路由处理（`.js` 文件内容中 `__CACHE_VERSION__` 替换为启动版本）；`/assets/*` 由路由处理（`default.png` 返回 JSON 占位而非图片文件）。
- **`sw.js`**：返回空脚本占位（Service Worker 架构已废弃）。

---

## 7. 明确不在后端直接承载的范围

| 项目 | 说明 |
| --- | --- |
| **后端直出 HTML（landing.html 等）** | 已移除；原 `/`、`/chat`、`/html/index.html` 等均改为重定向，不再由后端直接返回 HTML 页面 |
| **剧情模式** | 规划中，**第一期仅 Android**（见 `docs/design/剧情模式设计.md` §2.6）；网页端不提供入口 |
| **游戏 / 锁分模式** | 仅 Android 原生客户端；网页版对话固定为普通聊天 |

---

*如需新增面向内网的调试页，建议单独路径并加环境开关，避免与公开产品策略混淆。*
