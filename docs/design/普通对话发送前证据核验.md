# 普通对话由 Agent 自行查证

当前实现按用户要求，由负责回复的 Agent 在同一次任务内完成：拟稿 → 识别需要证据的断言 → 核对原始依据或调用工具查证 → 必要时修改并重新自检 → 输出最终回复。Agent 在同一最终 JSON 的 self_check 工作区先拟稿、逐项标注依据和修订，再输出 used_facts 及最终正文；传输解析器移除 self_check，用户只看正文。这些元数据不由另一个模型审批，不增加模型调用。不再启动独立断言提取模型或独立核验模型，也没有服务端事实审批步骤。

范围包括身份、物种、身体、偏好、关系、共同经历、时间、频率和操作完成状态。角色资料只能证明角色设定；旧助手回复不能证明用户事实；计划不等于发生；习惯不等于近期经历。证据已在上下文中时直接使用，缺少必要依据时使用原有 search_memory/read_history 工具；无关的装饰性细节直接删改，不机械检索。

情感、关心、玩笑、主动邀请及合理的新动作不需要历史发生证据。只修订无依据的事实片段，保留角色语气、主动话题和情绪，不让角色沉默、不断求证或退成谨慎套话。内部草稿、自检过程和工具日志不出现在用户正文。

原有 JSON 传输校验、明确记忆/表情包请求完成检查、用量计费和有界工具预算继续工作；这些不充当事实核验模型。格式重试保留已取得的原始工具结果。最终内容按既有发送和持久化流程交付，手机锁竞争和 SSE 保活修复保留。

autonomous_evidence.py 和旧的 run_evidence_review_probe.py 仅保留供历史对照复现；生产普通对话不导入、不调用独立核验流程。历史 reports 中关于独立核验门槛的描述仅对应当时版本。

提示词自检依赖模型执行，不能声称后端仍能保证逐条事实已通过独立审批。真实模型测试需覆盖隐含身份、虚构昨天、计划完成状态、历史检索和主动表达；自动化替身测试只能验证调用链、检索和格式重试行为。

用户进一步确认：目标是消除大部分明显错误，保留角色自然发挥。角色当下的普通生活状态和氛围可演绎；主要查证用户属性、共同往事、既有约定、固定设定及真实操作结果，不将每句场景描写都当作需要证明的事实。
