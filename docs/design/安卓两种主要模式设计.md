# 安卓端主要模式（产品设计）

> 与当前代码对齐：Android 当前仍提供 **普通对话 / 游戏模式（Galgame） / 锁分模式** 三条已实现路径；剧情模式仍是独立规划稿，尚未落地为可用功能。  
> **公开网页端**提供轻量普通对话 `/app`，不提供 Galgame / 锁分 / 剧情模式；详见 `docs/design/网页设计.md`。

## 1. 普通对话（含陪玩）

- 用户与角色的日常私聊；可包含 **陪玩**（语音/悬浮窗等由陪玩模块与 `ROADMAP` 中「聊天陪玩」阶段约定）。
- 记忆、模型策略、MLP RAG 等均以 **普通聊天（`normal`）** 为准。

## 2. 游戏模式（Galgame）

- 好感度导向的独立游戏会话，服务端实现位于 `Backend/galgame/`，接口包括 `/api/chat`（`mode=galgame`）、`/api/galgame/state`、`/api/galgame/reset`。
- 与普通聊天的长期记忆、主动消息、MLP RAG 隔离；分层记忆契约见 `Backend/docs/galgame_tiered_memory_api.md`。

## 3. 锁分模式

- 锁分是 Galgame 的特殊模式，服务端和客户端仍保留；入口受权限限制，普通用户不可直接使用。
- 锁分包含体征、器官/情绪级联、死亡条件等额外状态，主要实现同样位于 `Backend/galgame/`。

## 4. 剧情模式（规划中）

- 与角色进入 **虚拟剧情线**，游玩结果可写入 **角色记忆**（长期关系与叙事进度）。
- 实现细节以落地时的接口与 `ROADMAP` 为准；它是未来规划，不等同于当前已实现的 Galgame / 锁分流水线。
