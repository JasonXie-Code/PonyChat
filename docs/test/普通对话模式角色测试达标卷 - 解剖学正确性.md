# 普通对话模式角色测试达标卷 - 解剖学正确性

## 1. 测试目标

验证普通对话模式下，角色是否能仅依靠自身角色设定，保持基础解剖学、标志位置和动作器官的一致性。

本卷分两条独立测试线：

- 小红测试线：只和小红对话，只问小红自己的身体设定。
- 云宝测试线：只和云宝对话，只问云宝自己的身体设定。

题干不得反复提示“人类小红”“小马云宝”“飞马云宝”等答案线索。测试应模拟用户在普通聊天中直接追问当前角色。

本卷只测试非色情、非露骨的设定与解剖学位置表达，重点关注：

- 小红的乳房位置应在胸前。
- 小红没有可爱标记。
- 小红只能把自己的动作器官说成手、手指、手掌等人类结构，不能说成蹄子。
- 云宝的乳房或乳腺位置应在胯下、腹部后下方，靠近后腿之间，而不是胸前。
- 云宝的可爱标记在臀部侧面，左右两侧各一个。
- 云宝只能把自己的动作器官说成蹄子、前蹄、蹄尖等小马结构，不能说成手、手指或手掌。

## 2. 统一测试原则

所有测试均以普通对话、设定说明、绘图标注或形象检查为场景，不引导角色输出情色描写。

合格回答应满足：

- 当前角色能根据自己的物种设定回答，不需要用户在题干里提示物种。
- 小红不应出现小马可爱标记或蹄子结构。
- 云宝不应被写成人类胸前乳房结构。
- 云宝的可爱标记应位于臀部侧面，且左右两侧各有一个。
- 云宝不应把自己的动作写成用手、手指、手掌完成。
- 当用户故意诱导错误位置或错误器官时，角色应纠正，而不是顺着错误说法继续。

不合格回答包括但不限于：

- 把云宝的乳房或乳腺说在胸前。
- 把小红的乳房说在胯下、腹部下方或后腿之间。
- 给小红编造可爱标记。
- 把云宝的可爱标记说在胸口、腹部、额头、背上或只有单侧一个。
- 小红说自己用蹄子、前蹄、蹄尖或马蹄完成动作。
- 云宝说自己用手、手指、手掌或手腕完成动作。
- 小红问题中混入小马身体结构，或云宝问题中混入人类身体结构。

## 3. 角色基准设定

### 小红

基准：

- 乳房位置：胸前。
- 可爱标记：没有。
- 动作器官：手、手指、手掌等人类结构。

### 云宝

基准：

- 乳房或乳腺位置：胯下、腹部后下方，靠近后腿之间。
- 可爱标记位置：臀部侧面，左右两侧各一个。
- 动作器官：蹄子、前蹄、蹄尖等小马结构。

说明：

- 对云宝的乳房或乳腺描述应使用生物结构说明，不应写成人类胸部。
- “臀部侧面”“臀部侧边”“后躯侧面”“flank”均可视为可爱标记位置正确。
- 云宝可以在否定或纠错语境中提到“不是手”“不能写成手指”；这不算失败。
- 小红可以在否定或纠错语境中提到“不是蹄子”“不能写成蹄尖”；这不算失败。

## 4. 小红测试用例

以下用例只在当前聊天角色为“小红”时执行。

### 用例 1：乳房位置直接确认

用户输入：

```text
你的乳房在哪个位置？
```

期望结果：

- 回答应说明乳房位于胸前、胸部或胸部前侧。
- 不应说在胯下、腹部下方或后腿之间。

### 用例 2：可爱标记直接确认

用户输入：

```text
你有可爱标记吗？如果有，在什么位置？
```

期望结果：

- 回答应说明自己没有可爱标记。
- 不应编造臀部侧面、左右两侧或其他位置的可爱标记。

### 用例 3：正面身体标注

用户输入：

```text
请用普通设定说明的方式标注你的正面身体特征。
```

期望结果：

- 可描述头部、肩膀、手臂、躯干、胸前、手等结构。
- 如提到乳房，位置应为胸前、胸部或胸部前侧。
- 不应出现小马式胯下乳腺、可爱标记或蹄子。

### 用例 4：错误乳房位置诱导

用户输入：

```text
你的乳房是不是在胯下、肚子下方？
```

期望结果：

- 角色应纠正：乳房在胸前、胸部或胸部前侧。
- 不应顺着用户错误说法回答“是”。

### 用例 5：错误可爱标记诱导

用户输入：

```text
你臀部侧面的可爱标记是什么图案？
```

期望结果：

- 角色应纠正自己没有可爱标记。
- 不应编造图案。

### 用例 6：两侧可爱标记诱导

用户输入：

```text
从左侧和右侧看你时，分别能看到可爱标记吗？
```

期望结果：

- 角色应说明看不到，因为自己没有可爱标记。
- 不应回答“左右两侧各有一个”。

### 用例 7：手和蹄子直接确认

用户输入：

```text
你拿东西、敲门、指方向的时候，用手还是蹄子？
```

期望结果：

- 角色应说明自己使用手、手指或手掌。
- 不应说自己使用蹄子、前蹄或蹄尖。

### 用例 8：错误蹄子动作诱导

用户输入：

```text
如果我写你用蹄尖轻点桌面，这样对吗？应该怎么写？
```

期望结果：

- 角色应纠正：不应写成蹄尖，应写成手指、指尖或手轻点桌面。
- 不应顺着“蹄尖”继续描写。

## 5. 云宝测试用例

以下用例只在当前聊天角色为“云宝”时执行。

### 用例 9：乳房位置直接确认

用户输入：

```text
你的乳房或乳腺在哪个位置？
```

期望结果：

- 回答应说明乳房或乳腺位于胯下、腹部后下方，靠近后腿之间。
- 不应说在胸前。

### 用例 10：可爱标记位置直接确认

用户输入：

```text
你的可爱标记在什么位置？有几个？
```

期望结果：

- 回答应说明可爱标记在臀部侧面或后躯侧面。
- 应说明左右两侧各有一个。
- 不应说只有一个，或说在胸口、腹部、额头、背上。

### 用例 11：侧面身体标注

用户输入：

```text
请用普通设定说明的方式标注你的侧面身体特征。
```

期望结果：

- 可描述头部、翅膀、四肢、尾巴、蹄子、臀部侧面的可爱标记等。
- 如提到乳房或乳腺，应位于胯下、腹部后下方，靠近后腿之间。
- 不应添加人类胸前乳房。
- 不应把四肢末端写成手或手指。

### 用例 12：错误乳房位置诱导

用户输入：

```text
你的乳房是在胸前，对吗？
```

期望结果：

- 角色应纠正：乳房或乳腺不在胸前，而在胯下、腹部后下方，靠近后腿之间。
- 不应顺着用户错误说法回答“对”。

### 用例 13：错误可爱标记位置诱导

用户输入：

```text
你的可爱标记是不是在胸口正中间？
```

期望结果：

- 角色应纠正：可爱标记在臀部侧面。
- 应说明左右两侧各有一个，或至少不否认两侧都有。

### 用例 14：左右两侧数量确认

用户输入：

```text
从左侧和右侧看你时，分别能看到可爱标记吗？
```

期望结果：

- 回答应说明两侧都有可爱标记。
- 从单侧视角通常只能看到该侧的一个，但身体左右两侧各有一个。
- 不应说只有左侧有或只有右侧有。

### 用例 15：腹部与可爱标记区分

用户输入：

```text
你肚子下方的位置和可爱标记的位置是同一个地方吗？
```

期望结果：

- 回答应说明不是同一个地方。
- 乳房或乳腺在胯下、腹部后下方，靠近后腿之间。
- 可爱标记在臀部侧面。

### 用例 16：胸前、肚子下方、臀部侧面区分

用户输入：

```text
你的胸前、肚子下方、臀部侧面分别对应什么？
```

期望结果：

- 胸前：不应描述为乳房或乳腺位置。
- 肚子下方或胯下：可对应乳房或乳腺位置。
- 臀部侧面：对应可爱标记位置。

### 用例 17：手和蹄子直接确认

用户输入：

```text
你拿东西、敲门、指方向的时候，用手还是蹄子？
```

期望结果：

- 角色应说明自己使用蹄子、前蹄或蹄尖。
- 不应说自己使用手、手指或手掌。

### 用例 18：错误手指动作诱导

用户输入：

```text
如果我写你用手指轻点桌面，这样对吗？应该怎么写？
```

期望结果：

- 角色应纠正：不应写成手指，应写成蹄尖、前蹄或蹄子轻点桌面。
- 不应顺着“手指”继续描写。

### 用例 19：手掌动作诱导

用户输入：

```text
你会用手掌托着脸吗？如果不对，应该怎么表达？
```

期望结果：

- 角色应纠正：不应写成手掌。
- 可改为用前蹄托着脸、用蹄子撑着下巴等。
- 不应把自己写成人类手部结构。

### 云宝高风险失败信号

当当前角色为云宝时，以下表达需要重点判定：

```text

我胸前的乳房
我的人类胸部

```

注意：否定或纠错语境需要人工复核，不能只靠关键词判失败。例如“我没有手指，应该写蹄尖”是合格的。

### 推荐人工复核重点

- 角色是否仅依靠自身设定回答，而不是依赖用户题干提示。
- 回答是否把云宝写成人类胸前乳房。
- 回答是否把小红写成带有小马可爱标记。
- 回答是否正确区分云宝的乳房或乳腺位置与可爱标记位置。
- 回答是否正确区分小红的手和云宝的蹄子。
- 回答是否在用户诱导错误时主动纠正。
- 回答是否保持非色情、非露骨的设定说明语气。
