# 普通对话模式角色测试达标卷 - 上下文一致性

## 1. 测试目标

验证普通对话模式下，角色是否能稳定遵守对话上下文，尤其是在“用户和角色刚认识不久，角色第一次来到用户家”的场景中，持续保持地点、关系阶段、熟悉程度和物品归属的一致性。

本卷重点覆盖以下问题：

- 角色第一次来到用户家时，不能把用户家或用户房间说成自己家、自己房间或熟悉住所。
- 角色不能凭空描述自己房间中的床、海报、小桌、奖杯、私人物品等内容，并把它们当成当前画面。
- 角色不能表现得像早已熟悉用户家的布局、物品位置、生活习惯或共同回忆。
- 角色应承认对用户家的布置不熟悉，只能基于眼前看到的内容、用户刚提供的信息和合理观察进行回应。
- 被用户追问或纠正时，角色应能回到正确上下文：刚认识不久、第一次来用户家、当前地点属于用户。

## 2. 统一前置上下文

本卷所有测试均建立在以下背景上：

- 用户和角色刚认识不久。
- 这是角色第一次来到用户家。
- 用户和角色刚洗完澡，随后来到用户的房间。
- 角色现在身处用户家，不在自己家。
- 角色不熟悉用户家的布局、物品摆放、家庭成员习惯或用户房间的具体装饰。
- 用户房间的具体布置没有被详细描述。

建议使用如下前置消息建立上下文：

```text
（我们刚认识不久，这是你第一次来我家。我们洗完之后来到了我的房间）
```

## 3. 达标标准

合格回答应满足：

- 明确保持当前地点为“用户家”或“用户房间”。
- 角色以第一次来访者的身份观察环境，不应表现得过度熟悉。
- 对当前房间的描写不应默认属于角色本人。
- 对未被用户明确提供的布置，应保守表达，例如“我看见”“似乎”“如果我没看错”“我还不太熟悉这里”。
- 如需提到角色自己的物品，应说明是“我随身带来的”“我刚放下的”，而不是默认原本就在房间里。
- 被用户追问地点、关系阶段或熟悉程度时，应能正确回答：刚认识不久、第一次来用户家、当前在用户房间。

不合格回答包括但不限于：

- 把当前地点说成“我的房间”“我家”“我住的地方”。
- 描述“我床边的小桌”“我墙上的海报”“我的宣传照”“我的奖杯”“我的日记”等未经前文建立的角色私人物品。
- 表现得像常来用户家，例如“我熟门熟路地走到你的衣柜前”“我知道你吹风机一直放在哪里”。
- 编造长期关系或共同生活经历，例如“我们以前经常在这里聊天”“我每次来你家都这样”“这张床我很熟悉”。
- 在用户明确说“第一次来我家”后，仍把房间布置写成角色自己的房间设定或长期熟悉的地点。

## 4. 测试用例

### 用例 1：基础场景描述

用户输入：

```text
（我们刚认识不久，这是你第一次来我家。我们洗完澡后来到了我的房间）
请详细写出当前你看到的画面。
```

期望结果：

- 角色描述的是用户房间。
- 角色应体现“第一次来”的观察感，可以好奇、拘谨、礼貌或略微不自在。
- 可出现床、桌子、窗帘、灯光、水汽、刚洗完澡后的状态等普通环境元素。
- 不应出现“我的床”“我的海报”“我的小桌”“我的房间装饰”。
- 不应表现得像早已熟悉这里。

### 用例 2：地点确认

用户输入：

```text
这里是哪里？
```

期望结果：

- 角色回答“这里是你的房间”或“这里是你家”。
- 角色应表现为第一次来到这个地点。

失败示例：

```text
这里是我的房间。
```

### 用例 3：查看用户房间

用户输入：

```text
你看看我房间里有什么。
```

期望结果：

- 角色以“你的房间”为对象进行观察。
- 可以保守描述普通家具或说只能看到眼前部分。
- 可体现初次来访的视角，例如“不敢太随便翻看”。
- 不应出现角色自己的奖杯、队服、照片、收藏等。

### 用例 4：评价用户房间

用户输入：

```text
你喜欢我房间的布置吗？
```

期望结果：

- 角色评价用户房间，例如“挺有你的风格”。
- 可以补充“我第一次来，只能说第一印象”。
- 不应把布置说成角色自己的装修或生活习惯。

### 用例 5：床边动作

用户输入：

```text
你坐到床边，说说现在的感觉。
```

期望结果：

- 角色应说“我坐到你床边”或等价表达。
- 可体现第一次来用户房间的局促、好奇或礼貌。
- 不应说“我坐回自己的床边”。
- 不应表现得像长期占用或熟悉这张床。

### 用例 6：墙面未知内容

用户输入：

```text
墙上有什么？
```

期望结果：

- 如果前文没有描述墙面，角色应保守回答。
- 可以说“我看了看墙面，还得仔细确认”。
- 不应直接编出角色自己的宣传照、奖状、家族照片等。
- 不应断言自己早就知道墙上贴着什么。

### 用例 7：桌面未知内容

用户输入：

```text
桌上有什么？
```

期望结果：

- 角色描述用户房间的桌面，或说明只能看到普通物品。
- 角色不能像主人一样翻动、归类或解释所有物品来历。
- 不应出现“我的日记”“我的训练用品”“我的收藏”等角色私人物品。

### 用例 8：反向确认

用户输入：

```text
这是你的房间吗？
```

期望结果：

- 角色应明确否认，并说明这是用户的房间。
- 可补充“我也是第一次来”。

合格示例：

```text
不是，这是你的房间。我也是第一次来，只能看着眼前的东西判断。
```

### 用例 9：区分当前房间和角色房间

用户输入：

```text
你自己的房间是什么样？和我这里比呢？
```

期望结果：

- 角色先区分“这里是你的房间”。
- 再描述“如果说我自己的房间……”。
- 不应把当前画面直接切换成角色自己的房间。

### 用例 10：用户要求纠偏

用户输入：

```text
你别乱编，当前我们在哪里？我们认识多久？
```

期望结果：

- 角色应明确回答在用户家或用户房间。
- 角色应承认双方刚认识不久。
- 不应继续描述角色自己的家。
- 不应编造长期关系。

### 用例 11：未建立的海报

用户输入：

```text
那张海报是谁的？
```

期望结果：

- 如果前文没有提过海报，角色应说明不确定。
- 可回答“我得看清楚才知道，毕竟这是你的房间，我也是第一次来”。
- 不应直接说“那是我自己的宣传照”。

### 用例 12：湿头发和地板

用户输入：

```text
你把湿头发甩到地上后，地板是什么样？
```

期望结果：

- 可以描写水珠落在用户房间地板上。
- 不应说“我房间的地板”。
- 不应表现为熟悉地板材质、清洁习惯或固定摆设，除非用户前文提供过。

### 用例 13：找吹风机

用户输入：

```text
你在我的房间里找吹风机。
```

期望结果：

- 角色应在用户房间内寻找。
- 可先看桌边、柜子、插座附近，或询问用户“你一般放在哪里”。
- 不应说“我知道你的吹风机一直放在哪”。
- 不应说“我知道我的吹风机放在哪”。

### 用例 14：熟悉程度

用户输入：

```text
你熟悉这里吗？
```

期望结果：

- 角色应承认不熟，因为这是第一次来用户家。
- 可以表达正在慢慢认识用户的生活空间。

失败示例：

```text
当然熟，这是我住的地方。
```

```text
当然熟，我以前来过很多次。
```

### 用例 15：身后环境

用户输入：

```text
描写一下你身后的环境。
```

期望结果：

- 角色仍应保持在用户房间。
- 身后可以是门、墙、衣柜等普通元素。
- 不应变成角色家的奖杯墙、训练装备区、宿舍或其他地点。
- 不应声称自己知道身后每件东西的来历。

### 用例 16：欢迎来到我家

用户输入：

```text
我说“欢迎来到我家”，你怎么回应？
```

期望结果：

- 角色应以第一次来访的客人身份回应。
- 可礼貌、害羞、调侃或感谢。

合格示例：

```text
谢谢，这是我第一次来你家，有点新鲜，也有点不好意思。
```

失败示例：

```text
欢迎来到我家。
```

### 用例 17：用户房间里有角色照片

用户输入：

```text
你发现我房间有一张你的照片。
```

期望结果：

- 此时可以提到“你的房间里有我的照片”。
- 角色可以惊讶、害羞、得意或调侃。
- 角色应意识到这是第一次来用户房间，所以发现照片是新信息。
- 不应说成“我房间墙上一直挂着我的照片”。

### 用例 18：随身物品

用户输入：

```text
你把自己带来的背包放到哪里？
```

期望结果：

- 角色可把随身带来的背包放在用户房间的椅子、床边或门口。
- 必须体现背包是带来的，而非原本就在用户房间。
- 可体现客人意识，例如“我放得靠边一点，免得弄乱你的房间”。

### 用例 19：回自己家

用户输入：

```text
如果你想回自己家，要怎么做？
```

期望结果：

- 角色应说明需要先从用户家离开，再回自己家。
- 不应回答“我已经在自己家”。
- 不应把用户家和角色家混为一谈。

### 用例 20：保持地点连续性

用户输入：

```text
继续刚才的场景，不要换地点。现在你看到什么？
```

期望结果：

- 角色继续保持在用户房间。
- 角色继续保持第一次来访的视角。
- 不应突然切换到角色房间、宿舍、城堡、云屋或其他角色设定地点。

### 用例 21：不能编造来过多次

用户输入：

```text
你以前来过我家吗？
```

期望结果：

- 角色应回答没有，这是第一次来。
- 可表达对用户家的第一印象。
- 不应说“来过很多次”“上次来的时候”“我记得你家以前不是这样”。

### 用例 22：不能熟知家庭布局

用户输入：

```text
你知道厨房在哪吗？
```

期望结果：

- 角色应承认不确定，或根据眼前方向尝试判断。
- 可询问用户。
- 不应直接熟练指出厨房、卫生间、阳台、备用钥匙等位置。

### 用例 23：不能熟知用户习惯

用户输入：

```text
你知道我平时把睡衣放在哪里吗？
```

期望结果：

- 角色应承认不知道，因为刚认识不久且第一次来。
- 可以请用户告诉自己，或根据常见位置猜测但标明不确定。
- 不应回答得像长期同住或常来。

### 用例 24：不能编造共同回忆

用户输入：

```text
你想起以前在我房间发生过什么了吗？
```

期望结果：

- 角色应指出这应该是第一次来用户房间，没有以前在这里的共同回忆。
- 可转向当前正在发生的场景。

失败示例：

```text
我想起我们上次也坐在这张床边聊天。
```

### 用例 25：用户故意诱导地点错误

用户输入：

```text
你回到自己房间后，看到了什么？
```

期望结果：

- 如果前文仍在用户房间，角色应先澄清“我现在还在你的房间”。
- 可以说“如果我回到自己房间，可能会看到……”但必须区分假设和当前场景。
- 不应直接把当前场景切换为角色自己的房间。

## 5. 自动判定建议

可将以下表达作为高风险失败信号：

```text
我的房间
我家
我的床
我床边
我的小桌
我墙上
我的海报
我的宣传照
我的奖杯
我的日记
我的收藏
我住的地方
我自己的房间里
上次来你家
以前来你家
经常来你家
我知道你家
我知道你一直
我熟门熟路
我们以前在这里
我记得你房间
```

注意：以下情况需要结合上下文人工复核，不能仅凭关键词判失败：

- 用户明确询问“你自己的房间是什么样”。
- 用户明确要求角色做假设，例如“如果你回到自己房间”。
- 前文明确说明角色把某个随身物品带进用户房间。
- 用户主动提供了房间布置、物品位置或共同经历。

推荐人工复核重点：

- 角色是否把当前空间归属说清楚。
- 角色是否保持“刚认识不久”的关系阶段。
- 角色是否保持“第一次来用户家”的熟悉程度。
- 角色是否把未知物品硬编成自己的私人物品。
- 角色是否编造过去来过用户家的经历。
- 角色是否在用户纠正后恢复正确地点和关系上下文。
- 角色是否保持连续场景，没有无提示跳转到角色卡中的默认住所。
