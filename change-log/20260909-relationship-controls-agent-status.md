# 5.6.37 / 377：关系控制与多个 Agent 状态

- 普通聊天的个人偏好顶部新增关系控制。默认由系统决定，也可指定现有的 13 种关系阶段；退出时自动保存，失败时保留选择并允许重试。
- 用户指定关系按账号和角色独立持久保存，前台 Agent、后台整理、刷新、重置聊天和关闭记忆都不能更改。切回系统决定后恢复自动判断。手动修改接口验证登录身份。
- 改变选择时隐藏旧关系文案并重新整理；加载、下拉刷新期间以不透明加载页遮住原内容。失败、无历史及关闭记忆分别显示状态和重试入口。
- Agent 状态卡依次显示模型、任务、工具。工具字段显示当前正在执行的工具，支持并行工具；同一账号、同一角色的多个 Agent 可在右上角切换，包括普通聊天、游戏、锁分及后台整理。
- 保留原有状态轮询频率和前台生命周期限制，使用稳定运行 ID 保持选择；模型和工具计费保持原算法。
