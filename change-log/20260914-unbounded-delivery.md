# 探索 60 秒，交付取消墙钟截止时间

用户要求：移除超时终止，只有模型响应失败才停止；探索延长到 60 秒，之后只能交付。

- 移除普通 Agent 外层 180 秒 wait_for、交付 80 秒及恢复 60 秒截止逻辑。兼容保留旧 deadline 参数，但不再据此终止生成。
- 探索开始后 60 秒关闭探索，转入交付；所有重试继承该探索截止时间，不能重新获得探索窗口。
- 交付 runtime、进程池和追加消息接收器支持 timeout=None；仅保留进程启动、工具 HTTP 协议等局部操作错误处理。显式取消仍清理并结算已消耗用量。
- 模型返回失败维持一次恢复；无效 JSON 维持现有有限修复，不能无限循环。交付 low 与 16384 输出上限不变。
- Android 普通模式恢复轮询不再因 60 次用完而显示 normal_recovery_timeout；仅当前会话当前生成期间等待，完成、失败、取消或切换后停止。
- Android 升级至 6.0.25 (403)，签名构建与单元测试通过。未连接 ADB 设备，未进行真机安装验收。
- 验证包含超过旧 180 秒的虚拟时钟交付、JSON 修复、模型失败、显式取消计费、无截止进程池及追加消息、图片传输幂等。
- 真实模型隔离 /api/chat SSE 验收通过（37.375 秒）；真实 SDK 无交付截止调用完成。此结果不是长时间生产压力测试。
- 回滚源码五个文件全部匹配旧发布标记原始 SHA256。
