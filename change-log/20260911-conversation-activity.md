# 6.0.10 / 388：对话动态卡片

- 对话设置中，在 Agent 状态上方新增「对话动态」卡片，显示角色已保存的短期续聊安排、预计尝试时间、准备中、取消、过期及失败等状态。
- 额外显示当前回复处理状态、主动消息开关、记忆整理状态及连续续聊轮数。普通/游戏/锁分按当前模式隔离，游戏模式不混入普通聊天的续聊安排。
- 与现有 Agent 状态共用前台轮询，后台停止请求；网络异常保留上次状态并标注，服务端不支持或读取失败显示未知，不误报没有安排。
- 新增只读后端查询，验证账号、角色、会话归属；根据实际设置、过期时间、后续用户回复和连续续聊上限投影状态，不修改调度、不输出内部计划/理由。
- 39 项后端测试、85 项 Android 单元测试、4 项模拟器状态与轮询测试通过，卡片截图已检查。
- 正式签名 APK 6.0.10 / 388 已发布，本机、CN 和官网版本接口及完整安装包 SHA-256 一致。按用户要求，本次只发布 App，后端由另一任务部署，本任务未重启后端。发布证据见 `docs/testing/conversation-activity-20260911/public-release.json`。
