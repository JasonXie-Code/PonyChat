# 2026-06-04 变更记录

## 个人数据导出

- 主站新增个人数据导出页面和路由，用户可以从网页侧发起个人数据打包导出。
- 后端新增数据导出接口，覆盖用户资料、角色、对话、普通记忆、语音状态、主动消息等主要数据。
- 管理后台补充数据导出和系统管理入口，便于后续排查生产问题时按用户维度留档。
- 前端新增统一复选框样式，导出页面和站内页面可复用一致的选择控件。

## 语音跟进与主动消息稳定性

- 计划跟进逻辑补强，避免语音回复、主动消息和普通回复在同一会话中互相抢顺序。
- 后端新增语音状态缓存与恢复测试，覆盖语音消息入库、缓存命中、ACK 清理和历史回退展示。
- 修复后台任务恢复能力，服务重启后可以更稳地恢复未完成的语音、主动消息和后台任务。
- Galgame SSE、普通非流式回复和消息路由增加恢复防守，减少异常重启后的丢消息风险。

## SQLite 与并发防守

- 数据库访问层继续收敛连接池和写入时序，减少语音链路高并发下的 SQLite lock。
- 角色内容权限、角色同步和消息语音状态写入增加测试覆盖。
- 后台服务 unit 调整运行参数，配合后端单进程 lifespan 任务，避免后台任务重复启动。

## Voice Lab 与 Qwen3TTS

- PonyChat 角色语音 recipe 改为自包含结构，降低克隆音色依赖外部文本或临时引用音频的概率。
- 修复 recipe clone 过程中参考文本泄漏到合成链路的问题。
- 角色克隆参考音频增加标准化处理，统一音量、格式和可用性。
- 新增参考音频批量标准化脚本，便于管理已有角色音色素材。
- 移动端语音音频传输链路提速，减少 App 等待语音气泡音频的时间。

## 管理后台与生产维护

- 修复管理后台角色列表行处理，避免官方引用、隐藏角色或大厅角色混合时显示错误。
- 管理后台角色区补充语音策略、官方状态和角色资料字段展示。
- 生产部署链路继续保持增量上传、语法检查、服务重启和 `/api/health` deploy token 探活。

## 验证

- 语音缓存、计划跟进、角色权限和数据库连接相关测试继续扩展。
- 生产后端多次部署到 Server-USA，并通过健康检查确认新进程加载。
- Qwen3TTS 与 Voice Lab 相关改动通过真实合成和移动端播放路径验证。
