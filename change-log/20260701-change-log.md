# 2026-07-01 Change Log

## 中国象棋对局流程

- 中国象棋继续增强完整对局流程，覆盖从聊天入口、角色资料、小游戏仓库到 Activity 页面导航的链路。
- Android 导航增加中国象棋入口，角色 ViewModel 与小游戏仓库能够读取并传递对局所需的角色、用户和配置数据。
- 中国象棋 UI 继续调整角色区、棋盘、候选走法、底部操作和消息输入，让对局状态、角色反馈和用户操作更连贯。
- 棋盘领域模型、引擎和候选走法继续扩展，支持更多胜负、将军、移动合法性和用户可选走法判断。
- 中国象棋音效组件继续打磨，配合拿起、落子、吃子、将军、被将军、胜利和失败等事件。

## 小游戏后端与记忆

- 后端 `minigames` 路由继续扩展中国象棋准备、执行、走法、结算和记忆提交协议。
- 中国象棋记录新增更完整的对局摘要、关键片段、最近对话、走法明细和互动事实整理，方便结束后写入普通对话记忆。
- 记忆提交重点保留赌注、赌约、惩罚、兑现条件、投降、认输、悔棋、输赢挑衅、用户要求和角色回应等高价值互动事实。
- 普通记忆整理提示新增小游戏/对局记忆保真规则，要求胜负和走法之外的互动细节也要中性保留，避免后续用户追问“刚才赌注是什么”时只剩泛化摘要。
- 用户事实守门测试补充小游戏记忆规则，避免对局内互动被错误降级成无具体内容或被整理成当前仍在进行的棋盘事实。
