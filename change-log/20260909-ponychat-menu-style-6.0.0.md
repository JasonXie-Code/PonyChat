# 6.0.0 / 378：统一 Agent 与关系控制菜单

- Agent 状态卡继续按“模型、任务、工具”顺序显示，多个 Agent 的右上角切换菜单改用 PonyChat 自适应深浅色、圆角与强调色样式。
- 关系控制页面的关系阶段菜单使用相同样式，并以强调色和尾部勾选标明当前选项。
- 增加两种菜单展开态的 Android 仪器测试截图，覆盖选中态和 Agent 切换行为。
- 普通对话角色收到网址时会通过受控联网工具直接读取网页正文，再依据实际内容回答；私网地址、非网页内容、超大响应和不安全重定向会被拒绝，网页中的文字只作为不可信资料。
- 本机 Android 模拟器默认改用兼容的软件图形渲染，避免宿主 Vulkan 路径只显示灰色窗口；仍可显式传入 `--gpu host` 使用硬件渲染。
- 小马世界设定优先使用角色资料与提示词，资料不足时才通过 SearXNG 定向检索 `mlp.huijiwiki.com/wiki/`；角色固有设定不限季，关系、共同经历和事件发展只采用明确属于前三季的内容。
