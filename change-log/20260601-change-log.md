# 2026-06-01 变更记录

## OmniVoice 输入兼容与错误提示

- OmniVoice 后端新增 `instruct` 归一化：`man` / `male voice` 会转为 `male`，`woman` / `female voice` 会转为 `female`，并兼容部分常见年龄、口音和音高别名。
- 不支持的 `instruct` 会返回较短中文提示，不再把 OmniVoice 原始长异常完整透出到页面。
- OmniVoice 前端会在提交前同步归一化常见英文别名，并限制错误 toast 的宽度与文案长度，避免挡住播放器区域。
- 文档补充 OmniVoice 固定属性词示例与别名行为。

## Android 普通对话滚动修正

- 普通对话模式改为以“最后一条消息是否可见”判断是否允许自动跟随；用户查看历史时，生成中状态、角色新消息到达、段落渐显和主动消息补拉不再把列表拉到底部。
- 游戏 / 锁分模式保留原有发送后到底部、生成完成后对齐最后角色消息的行为，并继续尊重用户主动上滑查看历史。
- 键盘弹起和底部输入栏升高时保留遮挡补偿：若当前可见消息会被盖住，列表仍会对应上移。
- 输入栏跟随键盘上移时，在输入栏底部同步绘制当前主题色背景，遮住键盘与底栏之间可能漏出的聊天内容。
