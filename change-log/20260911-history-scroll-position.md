# 6.0.9 / 387：历史阅读定位与 Agent 模式隔离

- 修复快速向上翻历史时，分页完成强制恢复请求发出时的旧位置，导致页面向下跳、打断惯性滚动的问题。分页改为依靠稳定消息标识保留当前可见内容与偏移，不主动执行滚动定位。
- 分页触发按可见消息和当前数据定位，避免加载提示条增删导致重复请求；到达新一页顶部后仍可继续加载。
- 滚动回归矩阵新增请求中继续移动、加载失败、惯性滚动中返回历史三类情况，并覆盖连续翻页。保留新消息跟随、快捷消息、引用历史定位等现有测试。
- 对话设置的 Agent 状态卡及切换菜单只展示当前模式的运行记录。普通聊天、游戏、锁分分别过滤；切换模式清除旧选择，没有当前模式记录时显示空状态，不回退展示其他模式。
- 验证：85 项单元测试、14 场景滚动回归矩阵、两项 Agent 状态界面测试通过；正式 Release 构建与固定产品签名验证通过。
