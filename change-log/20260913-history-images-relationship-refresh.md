# Android 6.0.24 / 402

## 修复

- 历史浏览、搜索结果及图片筛选，从手机本地图片索引补回服务器文字记录对应的图片附件。读取按账号、角色、会话和消息 ID 匹配，兼容旧会话缓存，并过滤本机隐藏消息和重复图片。
- 关系页首次加载、失败和已加载状态共用滚动状态；失败页也应用下拉位移，刷新指示器与内容跟手显示。
- 手动刷新立即清空关系页旧内容并显示全部卡片骨架，生成完成后填回新内容。失败时显示失败状态，不将服务端附带的旧页面当作新结果。后台自动刷新仍保留现有内容。

## 验证范围

- Android 单元测试、签名 Release 构建及针对性模拟器测试。
- 模拟器使用合成账号和图片，验证本地图片恢复、隔离、筛选、实际图片像素、预览翻页、多选，以及关系页手指按住期间的位置变化和刷新内容替换。
- 截图及发布检查见 `docs/testing/history-refresh-6.0.24-20260913/`。
- 未连接用户截图中的手机；依赖本机保存的图片文件/索引，无法恢复已经被清除的原图。本次不改服务端用户图片保留策略，也不涉及关系内容生成模型的失败原因。
