# 角色头像：清晰度与来源说明

## 为什么 Fandom 上的图常常「糊」

1. **上传文件本身就不大**：早年 Hub 宣传、Facebook 配图多为几百像素宽，维基 `File:` 页里 `imageinfo` 的 `width`/`height` 就是上限，换任何下载方式也不会多出细节。
2. **CDN 动态格式**：同一 URL 可能返回 WebP；本仓库已用 Pillow 解码后统一存 JPEG；**若源已是 JPEG，现默认不再二次重编码**（见 `image_to_jpg.py` 的 `passthrough_jpeg`），避免再糊一层。
3. **剧集截图**：ID 图来自片源，清晰度取决于当年制作与导出，不是「高清剧照库」。

## 本仓库脚本在做什么

- `fetch_portrait_candidates.py`：从 `mlp.fandom.com` 的 **File 命名空间**拉 **API 给出的原图 URL**，候选默认 JPEG 质量 **93**，主头像 **95**（可调 `--quality` / `--final-quality`）。
- 无法魔法放大：若维基元数据写 222×214，保存后仍是小图。

## 若想要更清晰，有哪些路

| 思路 | 说明 |
|------|------|
| **维基上的 SVG** | 部分角色有矢量图（如 `File:...svg`），可转任意分辨率 PNG 再裁切；需在脚本里单独支持 SVG 下载与 `cairosvg`/Inkscape 栅格化（未默认接入）。 |
| **官方设定集 / 艺术集** | 纸质或电子版扫图，分辨率通常高于网页小图；需注意版权与使用范围。 |
| **蓝光 / 高清片源截帧** | 可做 1080p 特写，需自行承担版权与用途。 |
| **AI 超分** | Real-ESRGAN、waifu2x 等仅「放大」，不增加真实细节，可作展示用。 |

## 结论

**没有**与 Fandom 完全同权、又普遍更高清的「单一公开 API」；要明显变清晰，通常要换素材层级（矢量、设定集、自建截帧），而不是只换下载脚本。
