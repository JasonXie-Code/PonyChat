# The Vote

The Vote

剧集
可爱远征
角色
可爱标记童子军

白银勺勺
背景幼驹

《The Vote》是《我的小马驹：友谊就是魔法》第五季的第七首歌曲，也是第十八集“可爱远征”六首歌曲中的第二首。白银勺勺在这首歌中初次开嗓。歌中，可爱标记童子军为皮皮竞选学生会主席展开宣传，而珠玉冠冠则借威胁勒索，开空头支票等伎俩为自己竞选宣传，十分自私。

制作

这首歌是受音乐剧《女巫前传》的“What Is This Feeling?”启发而作。
