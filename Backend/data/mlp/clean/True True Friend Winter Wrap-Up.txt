# True True Friend Winter Wrap-Up

True True Friend Winter Wrap-Up（终极混搭）

《True True Friend Winter Wrap-Up》，也被称为“Winter Mash-Up”，是一首的混搭歌曲，为第三部原声专辑《Songs of Harmony》的附赠曲目。 这首歌混搭了“送冬清扫”的《Winter Wrap Up》和第三季“命运魔咒”的《A True, True Friend》。其中还包含马迷音乐家加布里埃尔·布朗的主唱部分。
