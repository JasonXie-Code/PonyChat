# 优质头像筛选标准（PonyChat / MLP 知识库用）

本文档定义「适合作为角色展示头像」的判据，供**人工审图**与脚本 `portrait_quality.py` 对齐。脚本只能利用**文件名**与**维基返回的宽高**做启发式；最终观感以人眼为准。

---

## 1. 目标用途

- **聊天 / 列表 / RAG 侧栏**：小图可读、角色可辨、风格统一偏「正剧设定」。
- **不是**：梗图、反应包、剧情恶搞帧、多角色合影里裁一角凑合。

---

## 2. 优先选用（加分方向）

| 类型 | 说明 |
|------|------|
| **剧集官方 ID** | 文件名常含 `ID SxEy`；造型与配色标准，表情中性偏多。全身居多，可作头像时再裁切。 |
| **品牌/渠道宣传图** | `promotional`、Hub、Hasbro 等；常为单马主体、光线稳定。 |
| **定装 / 礼服 / 季宣** | 与 ID 不同造型时可作第二张备选。 |
| **胸像或半身** | 同分辨率下信息密度高，更适合小圆头像。 |
| **构图干净** | 主体居中、背景不抢戏；避免整屏字幕、台标、多角色抢镜。 |

---

## 3. 避免选用（减分 / 一票否决）

| 类型 | 说明 |
|------|------|
| **表情包 / 反应镜头** | 夸张五官、怼脸梗、流汗、崩溃、邪笑、字面梗（如 Literal Video）等。 |
| **剧情恶搞帧** | 变形头身比、大字横幅梗（如 NERVICITED 类）、故意丑化。 |
| **主体不是目标角色** | 合影里主角是别人、水晶球反射里是别的角色、文件名有误导。 |
| **伪装 / 玩梗剧情** | 文件名含 `Fake`、`… as …`（他人扮成该角色）等。 |
| **人类 / EG** | 若条目为小马形态，避免 EQG 人类立绘（除非明确要 EG）。 |
| **导航条 / 超小图标** | 文件名含 `navbox` 或像素过小（如长边 &lt; 120）。 |
| **明显水印 / 台标** | 占画面比例大、遮挡面部（轻水印可容忍时再权衡）。 |

脚本侧已实现部分**英文文件名关键词**黑名单，见 `portrait_quality.py` 中 `_MEME_SUBSTRINGS` 等；人工筛选时**不限于**这些词。

---

## 4. 尺寸与比例（辅助）

- **过小**：长边过低则细节不足，仅适合占位，不宜当「优质」主头像。
- **极端细长**：过宽或过窄的横幅/分镜，作圆头像裁切损失大。
- **竖长全身 ID**：脚本会对「过高相对过宽」略降权；人工时仍可接受，但可优先裁胸像后使用。

---

## 5. 版权与来源（原则）

- 优先使用**有权使用**的素材（官方宣传、维基在许可下的截图等）。
- 用户自行从搜索引擎保存的图，需自行确认**版权与使用范围**；仓库内脚本**不**自动从搜索引擎批量下载。

---

## 6. 与自动化脚本的关系

- `fetch_portrait_candidates.py`：按维基多路搜索 + `portrait_quality` 打分，**减少**明显坏图，**不能**替代人工对构图与梗文化的判断。
- 人工导入目录中的图，可直接按**本节第 2–3 条**筛选；需要统一格式时用 `image_to_jpg.py`。

---

## 7. 修订

- 若产品侧对「要不要 EG」「要不要全身」有硬性规则，在本文件追加小节并改脚本策略。
